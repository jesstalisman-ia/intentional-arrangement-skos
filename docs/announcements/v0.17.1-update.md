# v0.17.1 — cleaner exports, provenance namespaces, and a validation work list

Ten releases have landed since the last update here, most of them driven by tickets from one very thorough user. If you filed an issue this month: thank you. Hard-refresh the editor (Cmd+Shift+R) to pick up the new build; the version badge in the Crosswalk tab should read v0.17.1.

## Exports you can publish as-is

The goal of this run was an export that passes a strict linter with nothing left to clean up.

- **Date literals are valid now.** A timestamp that slipped into a date field used to export as `"2026-08-16T12:05:34Z"^^xsd:date` — a dateTime lexical form outside the datatype's lexical space, rejected by Jena's `riot --validate`. Dates reduce to their calendar part on import and defensively on export, so an affected file heals on its next round trip. Each resource also carries one `dcterms:created` and one `dcterms:modified`, not two. (#55, #56)
- **Collections are described like concepts** (#58): `skos:prefLabel` for the name, `skos:inScheme`, and creation/modification dates. Notes stay `skos:note`.
- **Creators resolve to agents** (#59). A concept's `dcterms:creator` that names a registered agent exports as that agent's URI, the same practice the scheme uses. ORCID identities are honored.
- **Partitive entails broader** (#60). All three ISO 25964 hierarchy relations now assert `skos:broader`, matching the published iso-thes ontology, so no link exports without the hierarchy it entails.
- **Mirror preferred labels as `rdfs:label`** (#65, v0.17.1) — a new export option for generic RDF tools that read `rdfs:label` without reasoning over `skos:prefLabel ⊑ rdfs:label`. Off by default, so the standard export stays pure SKOS; in SKOS-XL mode it also labels the `skosxl:Label` resources, whose only text is otherwise `literalForm`. Preferred labels only — hidden labels stay hidden.

## Provenance gets its own namespaces

People and cited documents are metadata *about* a vocabulary, not members of it. They used to mint URIs beside your concepts, where they dereference as terms and can collide with them. Two optional scheme fields fix this (#57, #63): an **Agents namespace** for `prov:Person` / `prov:Organization` / `prov:SoftwareAgent`, and a **Documents namespace** for `foaf:Document` sources, falling back to the agents one when blank. Both are declared in every serialization (`@prefix agents:` and `@prefix resources:` in Turtle, matching declarations in RDF/XML and the JSON-LD context) and round-trip losslessly. Leave both blank and nothing changes. An explicit identity URI on a resource still wins.

## Validation as a work list

- **⬇ Report (Markdown)** in the Validate tab downloads the current findings as a checkbox list, grouped by severity and then by check, each item naming the concept and its identifier (#61). Work through fixes in the editor instead of bouncing between tabs.
- A new warning catches a **mapping that targets a vocabulary term** — a property or class of Dublin Core, FOAF, and friends rather than a `skos:Concept`. Easy to do, annoying to discover after publishing. (#62)
- **Unmarked top concepts** get flagged: a hierarchy root that would export without `skos:topConceptOf`, with a one-click fix. (#54)
- In the Graph's **Connect** mode, click a concept and the scheme hub to mark it a top concept.
- The **Glossary** warns loudly when a candidate list is linked to a different taxonomy than the one open, with a one-click relink — promoted terms no longer land where you can't see them.

## Under the hood

The app is now three static files instead of one: `index.html` for the interface, `core.js` for the standards engine, and `vocab-data.js` for the bundled reference vocabularies. There is still no build step and nothing uploads; download the `app/` folder and it runs. Every change now has to pass an automated browser check before it ships — the full concept form visible at a laptop-sized window, an export/import round trip that still works, and no console errors. That check found and killed a long-standing layout bug on its first run.
